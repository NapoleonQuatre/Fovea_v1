La voix est téléchargée une seule fois (premier moteur : environ 30 Mo en plus), puis gardée dans votre navigateur. Elle tourne sur votre appareil : le texte ne part nulle part. La première phrase demande quelques secondes de calcul.

MeloTTS est un modèle Python : il ne peut pas tourner dans une page web. Lancez python melo_server.py sur votre ordinateur (fichier fourni avec Fovea), puis gardez cette adresse. Le texte reste sur votre machine. Ne fonctionne que depuis la version locale de Fovea.
